## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer converts multiple signals into one output signal. 

### In plain English describe the function and use of a demultiplexer.
A de multiplexer passes one signal to one of a series of outputs. Like picking where the car air conditioning will come out

### What other uses might these circuits have? (Think Shannon’s)
Depending on the cost of multiplexers based on the cost of other logic gates it might be more cost effective to build with multiplexers. From Shannon's law we know that any boolean expression can be made using multiplexers. Maybe if we were limited to multiplexers for some reason, like if we were doing breadboard things again. It also means if there's a very complicated boolean expression that needs to get made into a circuit, it can be done with multiplexers confidently knowing one must exist as opposed to having to plan and figure out a way with other circuits.
